# 🥠 오늘의 묵상쿠키 (Daily Grace Cookie) 서비스 종합 기획서

> **"매일 아침 갓 구운 따뜻한 말씀 쿠키를 톡 깨뜨려 오늘의 은혜를 확인하고, 소중한 사람에게 선물하세요."**
> 
> - **문서 버전:** v1.0 (Production Ready)
> - **작성일:** 2026년 10월 15일
> - **플랫폼 형태:** 모바일 최적화 반응형 단일 페이지 웹앱 (SPA / PWA 확장 가능)
> - **기술 스택:** HTML5, Tailwind CSS, Vanilla JavaScript, HTML5 Canvas API, Web Audio API, LocalStorage

---

## 1. 프로젝트 개요 (Project Overview)

### 1.1 기획 배경 및 목적
* **일상 속 묵상의 게이미피케이션(Gamification):** 정적인 텍스트 위주의 기존 성경/묵상 앱에서 벗어나, '포춘쿠키를 터치해 바삭 깨뜨리는' 직관적인 모션그래픽과 청각·촉각(진동) 경험을 결합하여 매일 말씀을 찾아보는 즐거움을 제공합니다.
* **깊이 있는 묵상 큐레이션:** 단순 성경 구절 나열에 그치지 않고, **성경 원어(히브리어/헬라어) 어원 해설, 시대적 배경, 오늘의 실천 미션, 새벽 페어링 찬양(YouTube)**을 한 장의 플립 카드에 입체적으로 담아 풍성한 묵상을 돕습니다.
* **경험 중심의 나눔(Unboxing Gift):** 완성된 텍스트만 공유하던 기존 방식 대신, 받는 사람이 링크를 열었을 때 보내는 이의 축복 메시지와 함께 **직접 쿠키를 깨뜨려 말씀을 열어보는 '언박싱(Unboxing) 경험'**을 선물할 수 있도록 설계했습니다.

### 1.2 핵심 타깃 유저
* 출근길·등굣길 모바일을 통해 3분 내외로 깊이 있는 말씀과 찬양을 접하고 싶은 현대인
* 가족 단톡방, 소그룹, 지인에게 부담 없으면서도 감동적인 방식으로 말씀과 응원을 전하고 싶은 사용자

## 2. 정보 구조도 (IA, Information Architecture)

하단 플로팅 탭바(5개 메뉴)와 3개의 오버레이 모달로 구성된 직관적인 모바일 내비게이션 구조입니다.

```text
오늘의 묵상쿠키 (App Root)
├── [Header] 빠른 쿠키 뽑기 버튼 / 🎁 쿠키 선물하기 버튼 / 사용자 닉네임 설정
│
├── [Tab 1] 🏠 베이커리 홈 (Main Dashboard)
│   ├── 시간대별 다이내믹 인사말 (Morning / Afternoon / Evening)
│   ├── 4가지 맛(Flavor)별 맞춤 쿠키 즉시 오픈 그리드
│   ├── 3종 비비드 히어로 스탯 캐러셀 (내 쿠키 단지 수집률 / 30선 레시피 / 기프트 박스)
│   └── Today's Pick Cookie 하이라이트 프리뷰 카드
│
├── [Tab 2] 📅 오늘쿠키 (Daily Meditation Studio)
│   ├── 30개 쿠키 세로형 알약(Pill) 넘버 피커 (가로 스와이프)
│   ├── 3D 인터랙티브 플립 카드
│   │   ├── [앞면] 성경 본문 + 묵상 해설 + 공동 기도문 + 아멘 공감 카운터
│   │   └── [뒷면] 히브리어/헬라어 원어 산책 + 성경 배경 레시피 + 오늘의 실천 미션
│   ├── 맛(Flavor)별 프로그레스 바 카테고리
│   └── 페어링 새벽 찬양 & 한 줄 기도 노트 리스트
│
├── [Tab 3] 🥠 쿠키뽑기 (Interactive Motion Modal 호출)
│   ├── SVG 포춘쿠키 아이들링(Idle) & 터치 시 쉐이크(Shake) 모션
│   ├── 크랙(Crack) 물리 애니메이션 + Web Audio 화음/진동 + 골드 파티클 폭죽
│   └── 스크롤형 말씀 페이퍼(Slip) 언롤(Unroll) 뷰 & 선물/재뽑기 액션
│
├── [Tab 4] 📚 쿠키도감 (Archive & My Cookie Jar)
│   ├── 실시간 키워드 검색 바 (성경 장절, 제목, 본문 키워드)
│   ├── 6종 필터 탭 (전체 30 / 🫙 내 쿠키단지 / 허니 평안 / 시나몬 새힘 / 말차 지혜 / 베리 사랑)
│   └── 수집 여부(🥠 수집됨) 배지가 포함된 아카이브 카드 리스트
│
├── [Tab 5] 🖼️ 카드굽기 (Canvas Image Studio)
│   ├── 3종 배경 테마 선택 (퍼플 베이커리 / 골든 오븐 / 미드나잇)
│   ├── HTML5 Canvas 고해상도(800x1000px) 실시간 렌더링 프리뷰
│   └── PNG 이미지 즉시 다운로드 (카카오톡/인스타그램 공유용)
│
└── [Global Modals & Floating Bar]
    ├── 🎧 하단 미니 오디오 비주얼라이저 바 & 유튜브 인앱 찬양 플레이어 모달
    └── 🎁 지인에게 묵상쿠키 구워 선물하기 (언박싱 URL 생성기) 모달
